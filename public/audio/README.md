# Hausa voice prompts

Africa's Talking `<Say>` text-to-speech has no Hausa voice. To play real Hausa audio, drop MP3 files here as
`ha/<key>.mp3` (and optionally `en/<key>.mp3`). Korafi plays a file when it exists and falls back to TTS otherwise.

Keys: `welcome`, `lang`, `menu`, `category`, `area`, `done`, `record`, `recordPrompt`, `thanks`, `none`, `invalid`, `confirm`, `yes`, `no`.
