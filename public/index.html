The real problem

People can talk to businesses. Businesses can’t hear them at scale.

“There is no network in my area.”

A customer can say it in seconds. But the business never learns the things that matter — until Korafi turns that sentence into structured data.

Where is the problem?Which unguwa, which street.

How many people are affected?One customer, or two thousand?

When did it start?The first report is the real start time.

Is anyone fixing it?Customers get a ticket and honest updates.

Is it actually fixed?Customers confirm — and earn airtime for it.

How it works

From a basic phone to a resolved incident in four steps

Customers dial a short code. Everything else — tickets, clustering, updates and rewards — happens automatically.

01 · REPORT

Dial. Pick. Done.

Two taps: what’s wrong, and where. The complaint is already structured data.

1. Babu wuta 2. Babu ruwa 3. Matsalar network 4. Delivery problem 5. Sauran matsala
02 · TRACK

A ticket, instantly

An SMS ticket lands in seconds. For the first time, the customer has something to hold on to.

KORAFI: An karɓi rahotonka. Ticket: #KF2048
03 · UPDATE

One incident, many customers

The business sends one broadcast. Every affected customer is told in their own language.

Ana fama da matsalar network a Kabuga. Ana aiki a kai.
04 · REWARD

Confirm the fix, earn airtime

Customers verify the repair with one key press. The business gets a real resolution signal.

An gyara matsalar? 1. Eh 2. A’a → ₦50 airtime

Report → Ticket → Updates → Confirm → Reward.

It watches every report as it arrives. When several customers report the same problem in the same place within minutes, it opens a possible incident — with a confidence score — before your support team has read a single message.

Reusable · Containerised · Configurable

Deploy your own Korafi instance in minutes

Each customer gets an independent instance with its own brand, USSD code, areas, reward and database. Nothing is hard-coded to Kano — Kano is simply our first market.

  • Docker image with Postgres via docker compose
  • Configured entirely through environment variables
  • Hausa and English out of the box
  • Africa’s Talking sandbox mode for safe testing
# one instance per customer
BUSINESS_NAME=Kano Water Board
USSD_CODE=*384*39563#
SMS_SENDER_ID=KORAFI
DEFAULT_LANGUAGE=ha
DEFAULT_REWARD=50
SUPPORTED_AREAS=Kabuga,Hotoro,Tarauni,Sabon Gari
AT_USERNAME=your-app
AT_API_KEY=••••••••
DATABASE_URL=postgres://…

$ docker compose up -d
# → dashboard + USSD / SMS / Voice webhooks live
